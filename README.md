# 5-Stage Pipelined RISC Processor using Verilog HDL

## Overview

This project implements a **32-bit 5-stage pipelined RISC processor** using **Verilog HDL**. The processor improves instruction throughput by executing multiple instructions simultaneously across five pipeline stages. The design includes hazard detection, data forwarding, and pipeline registers to ensure efficient and correct instruction execution.

---

## Pipeline Stages

- Instruction Fetch (IF)
- Instruction Decode (ID)
- Execute (EX)
- Memory Access (MEM)
- Write Back (WB)

---

## Features

- 32-bit RISC Processor
- Verilog HDL RTL Design
- 5-Stage Pipeline Architecture
- Hazard Detection Unit
- Data Forwarding Unit
- Pipeline Registers
- FPGA Implementation
- Functional Verification using Xilinx Vivado
